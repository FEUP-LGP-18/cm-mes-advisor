## Two Layers

The full workspace has two layers:

| Layer               | Path                 | Meaning                                                                    |
| ------------------- | -------------------- | -------------------------------------------------------------------------- |
| Discovery workspace | `../`                | Project notes, partner context, startup script, archived support artifacts |
| Active app          | `../cm-mes-advisor/` | The Next.js application teammates edit and ship                            |

Most code changes happen in `cm-mes-advisor/`. The outer workspace explains why the app exists and how to run the support stack.

## Archived Support Stack

The local LibreChat and MCP package lives under:

```text
../98_archive/large-artifacts/LGP2026
```

The root `./start.sh` restarts this stack when running the full environment. The app does not expose the stack as the product UI.

Files in that folder are operational support artifacts. Do not copy secrets from `.env` files, local setup files, YAML, screenshots, or partner-provided packages into docs or commits.

## What To Trust First

When docs disagree, use this priority order:

1. partner scope and answers in `../02_partner-conversation/`
2. current app behavior in `cm-mes-advisor/src/`
3. app README and this docs site
4. design and discovery docs under `cm-mes-advisor/docs/`
5. archived or older materials

Older MVP docs can be helpful background, but they should not override the Excel-first Phase 1 direction.

## Duplicate File Caution

The app worktree currently contains many untracked local duplicates with ` 2` in the filename, such as `src/app/theme 2.ts` or `docs/design/agent-ui-canon 2.md`.

Treat those as local clutter unless a human explicitly says otherwise. Do not document them as canonical and do not clean them up unless asked.
